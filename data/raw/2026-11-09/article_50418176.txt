Find a fresh perspective Choose Orbit and drag to look around. Scroll to zoom; press F to fit your model. A few things before you begin. What do I need to run it? A desktop browser with hardware acceleration and WebGPU or WebGL2 support. Use a mouse and keyboard for modeling. You can also run BenchUp as a native Windows, macOS, or Linux app. Where does my work go? Your model is autosaved in this browser on this device. Use File → Save to download a .ketchup project you can keep or open again. Clearing browser data can remove autosaved work, so download projects you want to keep. There’s no cloud storage or account to set up. Can I use my existing models? Use File → Import/Export to import SketchUp (.skp) geometry or export Wavefront OBJ (.obj). Imports run locally. SketchUp textures, scenes, and some model features aren’t supported; OBJ export includes geometry without materials. Is BenchUp free? Yes. BenchUp is open source under the MIT license and written in Rust. Explore the code, read the full guide, or contribute on GitHub. A blank canvas. Plenty of possibilities.
