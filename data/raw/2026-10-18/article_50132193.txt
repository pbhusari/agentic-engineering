Pele in your app Explore Pele in use Examples API Theming Compatibility Security Pele is a lightweight open source library that renders Mermaid diagrams to SVG, themed with CSS variables . How it works Write Mermaid syntax, Pele renders it to SVG. Try editing the example below. Mermaid 1 flowchart TD 2 A [ Mermaid text ] --&gt; B { Flowchart? } 3 B -- Yes --&gt; C [ Pele ] 4 B -- No --&gt; D [ Mermaid ] 5 C --&gt; E ([ SVG ]) 6 D --&gt; E Pele Open in Playground Yes No Mermaid text Flowchart? Pele Mermaid SVG Use CSS variables to set colors and fonts. Color changes apply without re-rendering. Zero dependencies, 6× smaller, and up to 500× faster than Mermaid.js. Pele supports every diagram type built into Mermaid 12.1.0.
