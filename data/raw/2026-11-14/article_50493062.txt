Overview ggml 1.0.0 prunes the deprecated public API and the legacy DIAG_MASK ops, adds configurable YaRN truncation and FP8 support, and brings broad performance work across backends: few-row quantized matmuls and MoE fusion on CUDA/Metal, a Vulkan prefill FlashAttention path, a device-side MoE scheduler on SYCL, decomposed Adreno FlashAttention in OpenCL, new WebGPU kernels, expanded Hexagon op coverage, and scheduler improvements that avoid uploading unused inputs. API changes Pruned deprecated API and removed the legacy DIAG_MASK_INF / DIAG_MASK_ZERO ops, bumping the RPC protocol to reject incompatible peers ( llama/29801 , llama/31946 ) Added ggml_rope_set_truncate / ggml_rope_get_truncate to control YaRN correction-bound rounding ( llama/30206 , llama/30802 ) Implemented the backward pass for TRI ( llama/30712 ) Added MUL_MAT src1 precision tests and gating for ggml_prec_set_acc ( llama/31896 , llama/31851 ) Bumped the RPC protocol to v9 with faster loading and graceful failure on unreachable endpoints or failed handshakes ( llama/29413 , llama/30415 ) Core changes Scheduler skips uploading inputs that are not read and prefetches only inputs produced by earlier splits ( llama/31419 , llama/32100 ) MoE cache can compute a share of the cache misses on the CPU and copy the results back asynchronously ( llama/30966 ) Meta backend raises the compute view limit for buffers with few tensors ( llama/31447 ) Backend changes CUDA Added few-row MMQ for batch sizes 2-24 and MMVF for BF16 few-row matmuls ( llama/31533 , llama/31959 ) Added OCP FP8 support and fused NVFP4 gate/up matmuls with GLU in MMQ ( llama/28413 ,
